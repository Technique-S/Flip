# P7-V2-B adversarial acceptance architecture

All WB cases below are **PLANNED / NOT IMPLEMENTED / NOT TESTED as V2-B** at this checkpoint. Existing baseline probes corroborate native semantics only; existing V1/V2-A tests do not establish interactive wiring completion. Baseline `2fa7281ba01557f484cef2878e484b6e16f3ffd2`. See [contract](../architecture/P7_V2_B_WIRING_CONTRACT.md), [interaction spec](P7_V2_B_INTERACTION_SPEC.md), [risks/findings/ownership](../architecture/P7_V2_B_INTEGRATION_PLAN.md) and [execution evidence](../milestones/P7_V2_B_ARCHITECTURE_CHECKPOINT.md).

Test layers: **P** pure command/normalization with exact cloned-request assertions; **N** real canonical parse/compose/evaluate/compare; **B** Playwright using real local API, with held/reordered real responses where required; **M** manual assistive-technology/touch/performance observations. No fake compose success may serve as acceptance. Synthetic hostile inputs belong in new tests; accepted fixtures and historical evidence remain untouched.
