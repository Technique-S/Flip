## Capture contract

Record a supported local checkout with native solver opt-in. Display the exact commit,
platform and the word HISTORICAL near archived evidence. Use only approved public sample
projects; keep personal browser tabs, aliases, recovery data, local usernames and unrelated
windows out of the recording. Record ordinary user actions after a permitted human/browser
session is available; this audit does not bypass the Computer Use protection.

Existing isolated tests already exercised the demonstrated operations. Their success is
not a substitute for rehearsing this exact script, timing the final edit or a manual
assistive-technology session. Any wait trimmed in editing must be labeled; never speed up a
solver timer or present precomputed output as a newly completed live proof. Do not record
wallet, signing, gas-spending or publication-success scenes.

## Operator notes

- Do not imply the example's local half-adder has a new onchain address. Attribute existing
  dependencies and use the identity table in [the submission draft](M45_R2_SUBMISSION_DRAFT.md).
- Generic sample behavior mode and a declared trusted prior are different. The accepted
  regression uses `docs/schema/m45-debugging/examples/swapped-prior.execution.json` for
  correction. Explain any file transition, or rehearse a coherent prior-selection sequence.
- To avoid losing context, show the initial mismatching Portable project and its named
  vectors before the agent correction. The unmodified agent browser test is a reproducible
  reference for the explicit continue checkbox and separate revision-open step.
- A command that verifies DIFFERENT exits 1. STOP_AUTHORIZATION exits 9. Show status, not a
  misleading green terminal “deployment succeeded” caption.
- If live RPC is unavailable, use the archived sample and label the library segment recorded
  or synthetic. Do not fabricate an available current registry or remove UNKNOWN from a shot.
- No stock images, music or third-party logos have been cleared or added. Use owned footage,
  a rights-reviewed title card and captions; any new assets need attribution/rights checks.

## Manual accessibility and human trial record to collect

A human tester should record OS/browser/screen-reader versions, date, keyboard-only route,
expected and actual **spoken** feedback, result and workaround. Include import error,
DIFFERENT table, EQUIVALENT, UNKNOWN, correction, cancellation and STOP. Check focus lands
on the new meaningful heading/error, live-region announcements are useful and not repeated,
and trust labels are understood. Then ask a developer unfamiliar with Flip to install and
complete the unassisted local recipe; record observed failures/time without coaching first.
No such results were invented for this package. Caption review, final edit duration and
successful judge-access rehearsal remain outstanding.
