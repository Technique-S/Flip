# Technical Risks Register

| Rank | Risk | Severity | Likelihood | Evidence | Mitigation |
|------|------|----------|------------|----------|------------|
| **R1** | **Unsealed Factory & Upgradeable Processors (`isSealed = 0`)** | High | High | `xlayer_probe` verified `isSealed = 0` and factory impl already upgraded once (`0x336e9f...` vs TAP-10 `0x74956236...`). Beacon `0xf70d...` is upgradeable. | Pin & hash imported `REF` bytecodes locally; warn users if a dependency's onchain bytecode/impl changes; do not market `REF`s as immutable unless `isSealed == 1`. |
| **R2** | **Cross-Chain `REF` Address Collision (No `chainId` in Netlist)** | High | High | Identical factory & processor 1 addresses verified on both X Layer (`196`) and Base (`8453`, `"TapeOutTestBase"`). | Bind every imported circuit to `(chainId, cpu, id)` in CircuitForge's manifest/URLs; validate active RPC `chainId` before `REF` resolution or `tapeout()`. |
| **R3** | **Ecosystem Overlap (`tapeout.net`, `tapeout.pro`, `TapeOut.build`)** | High | Medium–High | TapeAPI catalog (37 tools) shows editing (`tapeout.net`), BLIF export (`TapeOut.build`), and task verification (`tapeout.pro`) already exist. | Scope MVP around **composition (`REF` import/wiring) + behavioral diffing + X Layer pre-flight**, not a generic NAND canvas. |
| **R4** | **Wiring Canary Intent Ambiguity (Mode C)** | Medium | High | `wiring_canary.py` showed symmetric-gate swaps are equivalent and distinguishable mutants need an intent anchor to name the "right" one. | Require user-supplied spec, truth table, test vectors, or reference circuit; clearly label Mode C comparisons as "behavioral diff" rather than "bug detected". |
| **R5** | **Stateful (`LATCH`) Equivalence Complexity** | Medium | Medium | 15 of 50 corpus circuits are stateful (`core#95–#107`); current SAT PoC only handles stateless nets. | Support k-beat trace diffing (bounded simulation / BMC) for stateful circuits in MVP; defer full unbounded equivalence proofs. |
| **R6** | **TAP-02 Draft Spec & Stale Docs / Phantom Deployments** | Medium | Medium | TAP-02 is Draft; TAP-10 factory impl hash is stale; Issue #44 Constitution circuit has `nextId=1`; X Layer testnet factory has no code. | Validate against live X Layer mainnet `eth_call` rather than trusting docs; surface `eth_call` revert reasons directly in UI. |
| **R7** | **Public RPC Latency (~1.3s/call) & Endpoint Failures** | Low–Medium | High | 3 of 4 mainnet endpoints failed; `rpc.xlayer.tech` median RTT is `1,317.3 ms`; scanning 45 circuits took 312 s. | Aggressive IndexedDB/local caching of immutable circuit netlists, batching, and configurable RPC URLs. |
