# Flip coding-agent rules

Codex is the lead. OpenCode/HY4 Flash is support.

1. Read `README.md`, `docs/audits/M05/MVP_CONSTRAINTS.md`, the PRD, `docs/architecture/FLIP_TECHNICAL_DESIGN.md`, `FLIP_AGENT_OWNERSHIP_MATRIX.md` and `FLIP_IMPLEMENTATION_DEPENDENCIES.md` before changing files.
2. Stay within the task's allowed write paths. No shared-file edits or new dependencies outside scope. Stop and escalate if work requires them.
3. All interface changes are Codex-owned. OpenCode may add independent fixtures and documentation on its own branch.
4. Never mislabel structural validation as publication. Only report observed facts. Timeout or resource limit => UNKNOWN. No unverified proof claims.
5. No signing keys, wallet connections, broadcast, payment or live publication.
6. Preserve audit files as immutable evidence. Do not fabricate truncated hashes, response bodies, or corpus cases from reports.
7. Report modified files, actual tests run, failures, blockers, source provenance and commit SHA.
8. Do not merge your own work directly to `main`.
